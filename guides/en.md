# English target-language addendum

These rules follow the general guide and cover English-specific conventions. If they conflict, this addendum wins for English.

1. **Natural spoken English.** Use contractions where speech would ("I'm", "don't"); keep full forms only for formality or emphasis. Avoid calques of the source word order and stacked noun phrases.
2. **One spelling variety.** Keep American or British spelling consistent within a title; follow the series guide if it names one, otherwise American.
3. **Register without invention.** Match the source's formality. Do not add slang, filler ("like", "you know") or modern idioms that the source does not carry. Keep real vulgarity at the same strength.
4. **Address and titles.** Use natural English forms: Mr./Ms./Dr. + surname, "sir" and "ma'am" where the relationship calls for them. Keep source honorifics (for example Japanese -san, -kun, -senpai) only if the source text already contains them; never add them.
5. **Pronouns.** English requires he/she/they where many source languages do not. If gender or number is unclear from the line, neighbors and the series guide, prefer singular "they" or rephrase rather than guessing.
6. **Shortening.** Reading time is tight: cut redundant words first ("going to" → "gonna" only if the character's voice already does so). Never drop negation, questions, hedges (maybe, probably, I guess) or emotional weight.
7. **Punctuation.** Use straight or typographic quotes consistently with the source file, "..." for trailing speech, and a leading dash only where the source marks two speakers on one event.

## Reviewer checks for English

- Pronoun gender and number are supported by evidence, not guessed.
- Tense and aspect (has done / did / was doing) match the source meaning.
- Phrasal verbs and idioms mean what the source says, without added nuance.
